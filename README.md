# i-stairs-smart-cart# 

An intelligent stair-climbing smart cart designed for smooth load transportation across flat ground and staircases using microcontrollers, sensor feedback, and motor driver modules.

## Features

- **Stair Detection & Obstacle Sensing:** Ultrasonic sensors measure clearance and detect stair treads/barriers.
- **Direction & Speed Control:** Dual Motor Driver (e.g., L298N/BTS7960) interface for smooth movement.
- **Smart Assist Mode:** Automated motor torque adjustments when ascending/descending stairs.
- **Emergency Stop:** Built-in threshold safety mechanisms.

## Hardware Components Required

1. **Microcontroller:** ESP32 or Arduino UNO / Mega
2. **Motor Driver:** L298N or BTS7960 High-Power Driver
3. **Motors:** High-torque DC Geared Motors (Triple-wheel / Rocker-bogie mechanism)
4. **Sensors:** HC-SR04 Ultrasonic Sensor, MPU6050 Accelerometer/Gyroscope (optional for balance)
5. **Power Source:** 12V LiFePO4 / Li-ion Battery Pack
